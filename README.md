# Daily Ascend — Landing page

Page de vente statique (HTML / CSS / JavaScript, en un seul fichier) pour **Daily Ascend**, un pack de 2 trackers Google Sheets (habitudes + tâches) et 3 bonus.

## Contenu
- `index.html` — la page complète, autonome et prête à déployer (aucune dépendance à installer).
- `.claude/launch.json` — configuration du serveur de prévisualisation local.

## Déploiement (Vercel)
1. Importer ce dépôt dans Vercel (ou déposer le dossier).
2. Aucune configuration nécessaire : `index.html` est servi à la racine.

## Aperçu local
Servir le dossier avec n'importe quel serveur statique, par exemple :

```bash
npx serve -l 4321 .
```
